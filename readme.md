# Ravindra Kumar — Senior Frontend Engineer & React Architect

Production-grade, highly polished React 18 personal portfolio demonstrating modern UI architecture, WebGL/Canvas shader primitives, high performance, and accessible web engineering.

**Live Deployment:** [https://ravindra-dev07.vercel.app/](https://ravindra-dev07.vercel.app/)

---

## 🚀 Key Highlights & Tech Stack

- **Framework:** React 18 (SPA Architecture)
- **Build Engine:** Vite 8 (Ultra-fast HMR & optimized bundling)
- **Styling & System Design:** Tailwind CSS v4 + Custom Utility Primitives
- **Animation & Motion:** Framer Motion + HTML5 Canvas 2D + Three.js GLSL Shaders
- **State & Data:** Native React Hooks, Zustand, TanStack Query
- **Email Delivery:** Direct EmailJS Integration (`service_aatkgzu`, `template_qk7gogf`)
- **SEO & Accessibility:** WCAG 2.1 AA Compliant, Open Graph Metatags, Twitter Cards, Schema.org JSON-LD Person Graph

---

## 🎨 Interactive React Bits Suite

This portfolio integrates customized high-performance components:

- **`<ClickSpark />`**: Canvas cursor spark particle effect
- **`<DecryptedText />`**: Matrix cipher text reveal effect
- **`<ShinyText />`**: Specular gradient typography highlight
- **`<ShapeWaves />`**: Fluid mathematical background SVG waves
- **`<GridDistortion />`**: Three.js WebGL real-time liquid image distortion
- **`<TechText />`**: Canvas 2D spring-physics draggable wordmark
- **`<DepthText />`**: Extruded 3D CSS perspective parallax title
- **`<CountUp />`**: Framer Motion spring-physics metrics counter
- **`<LogoLoop />`**: Continuous rAF technology stack marquee ticker
- **`<SpotlightCard />`**: Radial cursor-tracking spotlight cards

## 📁 Repository Structure

```
.
├── public/                # Static assets, images, favicon, robots.txt & sitemap.xml
├── src/
│   ├── components/
│   │   ├── layout/        # Navbar, Footer, MainLayout, ScrollToTop
│   │   ├── reactbits/     # Specialized interactive UI primitives & shaders
│   │   ├── sections/      # Hero, Projects, Capabilities, Approach, Experience, Contact
│   │   └── ui/            # Container, Loader, SEO, Button, Input, SocialIcons
│   ├── context/           # ThemeContext (Default Dark Mode)
│   ├── data/              # Profile, Projects, Capabilities, Principles & Career Data
│   ├── pages/             # Home, Projects, Services, About, Contact, Help, Privacy, Terms
│   ├── App.jsx            # Lazy route loading & global providers
│   └── main.jsx           # React DOM entrypoint
├── index.html             # HTML entry & pre-rendered SEO metatags
├── package.json           # Dependencies & scripts
└── vite.config.js         # Vite bundler configuration
```
